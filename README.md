# 마음 다리 · 친구 관계 상담 웹앱

반 학생들 사이의 친구 관계 고민을 선생님이 듣고 정리해, 상대 학생과 대화를 나누도록 돕는 웹앱입니다.

1. **이야기 들려주기** — 학생이 한 명씩 탭과 직접 쓰기로 상황·마음·바라는 것을 남깁니다.
2. **선생님 정리** — 비밀번호로 들어가 상담 가이드, 항목별 정리, 중립 요약을 봅니다.
3. **친구와 대화** — 먼저 본인의 이야기를 듣고, 좋은 점 → 친구들의 마음 → 약속 순서로 진행합니다.
4. **약속 카드** — 서로 해 볼 행동과 다시 확인할 때를 정리하고, 이미지(PNG)로 저장해 학생들에게 나눠 줄 수 있습니다.

상담이 끝나면 선생님 화면 맨 아래에서 모든 기록을 지워 주세요.

## 실시간 연결 (Firebase)

- Firebase 프로젝트 `school-counsel`의 Realtime Database에 저장합니다.
- 학생은 익명 로그인으로 **이야기 보내기만** 할 수 있고, 다른 사람의 이야기는 읽을 수 없습니다.
- 기록 읽기·정리·삭제는 선생님 Google 계정으로 로그인했을 때만 됩니다(보안 규칙으로 막혀 있음).
- 선생님 화면은 비밀번호 화면 → Google 로그인 순서로 들어갑니다.
