# 마음 다리 · 친구 관계 상담 웹앱

반 학생들 사이의 친구 관계 고민을 선생님이 듣고 정리해, 상대 학생과 대화를 나누도록 돕는 웹앱입니다.

1. **이야기 들려주기** — 학생이 한 명씩 탭과 직접 쓰기로 상황·마음·바라는 것을 남깁니다.
2. **선생님 정리** — 비밀번호로 들어가 상담 가이드, 항목별 정리, 중립 요약을 봅니다.
3. **남학생과 대화** — 먼저 본인의 이야기를 듣고, 좋은 점 → 친구들의 마음 → 약속 순서로 진행합니다.
4. **약속 카드** — 서로 해 볼 행동과 다시 확인할 때를 정리합니다.

기록은 서버에 저장되지 않고 사용한 기기(브라우저) 안에만 남습니다. 상담이 끝나면 선생님 화면에서 모두 지워 주세요.
